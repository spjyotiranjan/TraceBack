# Lucide icon primitives

[Handoff index](../README.md) · [Foundations](../foundations.md)

## Implementation contract

- Use the named native Lucide line icons with original 24×24 viewBox and strokes. Size via component design values, use currentColor to match foreground, and preserve 44 px targets independently of glyph size. Decorative icons are hidden to AT. Label any icon-only button at its container, including mobile dock and attachment controls.
