## Verification

- Compared 28 like-for-like Chromium states before/after. The new test runs at 1440×1040 and 390×844 in both themes, checks the 895/896px shell transition, performs touch recovery and footer navigation, and checks fixed-art viewport pixels during real document scroll. Art and layout are measured separately.
- Existing recovery and shared-controls Chromium journeys cover keyboard/skip focus, no-script safe retry, no POST replay, long reference reflow, and native 200% page zoom. Denied and Error at zoom, the missing report at zoom, and Privacy as guest and member at zoom all use real Chromium page zoom rather than DPR emulation.
- The Release suite covers real restricted member `/Admin` (302 to Denied 200; AJAX 403), guest challenge, unknown and deleted reports (true 404 for both identities, including deletion via the API in disposable MongoDB), unrelated/global 404, direct Error 200, and exception-reexecuted GET/POST 500. The retry is a query-free GET and the POST does not replay; neither response echoes exception text, query markers, or submitted fields. The deleted-record status check is HTTP integration coverage; the visual/browser missing-item matrix uses a deterministic unknown ID.
- No physical phone, production datastore, or live production exception was used. The browser runs against disposable loopback Kestrel and test fixtures, with real Razor and a disposable loopback MongoDB where persistence is required. PDF frames do not specify a guest Denied layout or missing-report guest layout beyond shared-shell reuse.
